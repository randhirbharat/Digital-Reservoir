# Synthetic example datasets

All files here are **synthetic**. They are generated by `generate_synthetic.py` with the documented
equations and do not describe any real structure. Each CSV starts with a `# SYNTHETIC ...` comment line.

| File | Content | Intended use |
|---|---|---|
| `demo_gravity_dam_daily.csv` | 3 years of daily crest displacement, reservoir level, air temperature, piezometric head and seepage. Includes deliberate missing values, duplicates and spikes for data-quality exercises | Data quality, HST, regression, PCA, ML |
| `demo_ambient_vibration_100Hz.csv` | 2-channel, 120 s, 100 Hz response with modes at 3.2 Hz (ζ = 2 %) and 7.9 Hz (ζ = 3 %) | FFT/PSD, modal identification |
| `demo_fragility_stripes.csv` | 11 PGA levels × 20 records with exceed/not-exceed outcomes (true θ = 0.55 g, β = 0.40) | Fragility fitting (MLE) |
