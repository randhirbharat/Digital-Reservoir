Data and model note

HST is represented here as a regression-style decomposition:

Y = hydrostatic component + seasonal component + time component + residual

Model quality depends on data duration, coverage, sensor reliability, variable selection, missing data, operating conditions and extrapolation. This implementation uses ordinary least squares in the browser for demonstration.
